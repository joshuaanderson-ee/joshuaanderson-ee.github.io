PROJECT STATUS: PLANNED

Digital Temperature Monitoring System

An embedded electronics project exploring temperature measurement, digital sensors, and communication between a microcontroller and a computer.

Project photos and diagrams coming soon

1. Project Objective

Build a temperature monitoring system using an Arduino and a digital temperature sensor. Collect readings, display measurements, and analyze temperature changes over time.

2. Components and Equipment

Planned components: Arduino Uno, TMP102 temperature sensor breakout board, breadboard, jumper wires, USB cable, and computer.

3. Circuit Design

Connect the TMP102 temperature sensor to the Arduino using I2C communication. Document the wiring diagram and explain the SDA and SCL connections.

4. Programming and Testing

Write Arduino code to read temperature measurements and display them through the Serial Monitor. Record measurements over time and evaluate sensor performance.

5. Challenges and Solutions

Document challenges involving I2C communication, sensor calibration, incorrect readings, and troubleshooting.

6. What I Learned

Reflect on the skills developed in sensor integration, digital communication, Arduino programming, and data collection.
