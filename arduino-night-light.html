PROJECT STATUS: PLANNED

Arduino Automatic Night-Light System

An embedded systems project using an Arduino and a light sensor to automatically control lighting based on ambient brightness.

Project photos coming soon

1. Project Objective

Design and program a microcontroller-based lighting system that detects changes in brightness and automatically activates an LED.

2. Components and Equipment

Planned components: Arduino Uno, breadboard, photoresistor, resistors, LED, jumper wires, and USB cable.

3. Circuit Design

A voltage divider will allow the Arduino to measure light levels using an analog input. A digital output will control the LED.

4. Programming and Testing

Arduino code, light sensor measurements, and testing results will be added here as the project progresses.

5. Challenges and Solutions

Troubleshooting notes, sensor calibration, and design improvements will be documented here.

6. What I Learned

A reflection on microcontroller programming, sensor integration, and circuit design will appear here.
